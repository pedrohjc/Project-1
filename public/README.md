# Pasta Public - Arquivos Estáticos

Esta pasta é para arquivos estáticos que podem ser acessados diretamente pelo navegador.

## Logo

Para adicionar a imagem do logo:

1. Coloque a imagem do logo nesta pasta como `logo.png` ou `logo.svg`
2. A imagem será automaticamente usada pelo componente Logo
3. Se a imagem não existir, o componente usará um SVG como fallback

### Requisitos da imagem:

- Formato: PNG (transparente) ou SVG
- Nome do arquivo: `logo.png` ou `logo.svg`
- Recomendado: Logo com fundo transparente
- Tamanho mínimo: 200x200px para qualidade em diferentes tamanhos
